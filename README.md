# Python Programming Practice

This repository contains my foundational Python scripts for practice and learning. 

## 📁 Files Included

* **`Hello.py`**: Basic starting script.
* **`Factorial.py`**: Calculates the factorial of a given number.
* **`Palindrome.py`**: Checks whether a given string or number is a palindrome.
* **`Prime.py`**: Checks if a given number is a prime number.
* **`design/`**: Folder containing additional design-related project files.

## 🚀 How to Run

To execute any of these scripts, ensure you have Python installed on your system. Open your terminal and run:
